# 標準ライブラリ

標準ライブラリは自動で読み込まれます。基本操作のためにincludeを書く必要はありません。Ruskで記述された追加データ構造は、それぞれのページで指定するファイルをincludeします。

| 目的 | 調べるページ |
|---|---|
| トークン・配列入力、EOF、行入力、出力形式 | [入出力](input-output.md) |
| 配列・文字列、ソート、添字、コピー | [配列と文字列](sequences.md) |
| Dict・Set、Optionを返す操作 | [辞書・集合](beta05.md) |
| map・filter、集計、探索、比較関数付きソート | [関数を使う操作](beta04.md) |
| Union-Find、Fenwick Tree、セグメント木 | [データ構造](data-structures.md) |

以下は基本APIの早見表です。個別ページでは入力例、共有、変更時の制限も説明します。

| API | 振る舞い |
|---|---|
| `Int` | 符号付き64ビット整数。四則演算・剰余・符号演算で独立した値を返す |
| `Bool` | `true` / `false`。出力は `Yes` / `No` |
| `Char` | ASCII の1文字 |
| `Str` | ASCII 文字列。添字による文字の共有・更新、連結、探索に対応 |
| `Vec<T>` | 要素を共有する可変長配列。基本型・構造体・タプル・多次元配列に対応 |
| `Unit` | 戻り値を省略した関数、または `-> Unit` と書いた関数の結果の型 |
| `copy(x)` | 基本型・配列・構造体・タプルの独立したコピー（内側も再帰的）。文字列は長さに比例、配列・構造体・タプルはコピー対象全体の大きさに依存 |
| `__assign__(a, b)` | 同じ型の `a` の中身に `b` をコピー。共有先の同一性を保つ |
| `__read__()` | `in` の指定型に応じて `Int`, `Str`, `Char`, `Bool` を読む |
| `__write__(x)` | 対応する値を区切りや改行なしで出力。配列・タプルは要素間に空白を入れ、末尾に改行は付けない |
| `assert(condition: Bool)` | 条件が偽ならソース位置付きで異常終了 |
| `read_line()` | 改行までを `Str` として読み、改行と末尾の CR を取り除く |

`Int` と `Str` の入力は空白区切りです。`Char` は先頭の空白を飛ばして1文字読みます。整数入力は符号を許し、トークン全体が整数であることを検査します。EOF、不正な入力、整数の範囲外、非ASCII文字の入力は実行時エラーです。

トークン入力は後続の区切り文字を消費しません。例えば整数の直後に `read_line()` を呼ぶと、同じ行の残りを先頭の空白も含めて読みます。直後が改行なら空文字列です。

`Int`, `Char`, `Str` は `== != < <= > >=`、`Bool` は `== !=` に対応します。比較は値を見て、独立した `Bool` を返します。`Str` の順序は辞書順です。

条件では `Bool` はその値、`Int` と `Char` はゼロ以外、`Str` は空でない場合を真とします。暗黙変換のための `__bool__` と比較の `__eq__`, `__ne__`, `__lt__`, `__le__`, `__gt__`, `__ge__` というフック名は暫定です。

## 標準APIの実装場所

標準APIには、通常のRusk関数として書いた処理と、C++の実装へ接続する`extern`関数があります。

| 処理 | 現在の実装 |
|---|---|
| `find<T>(a: Vec<T>, value: T)` | `lib/core.rusk`の通常の型引数付き関数。イテレータで走査し、`Option<Int>`を返す |
| 整数の`min`・`max`・`abs` | `lib/core.rusk`の通常の関数 |
| `<?`・`>?`・`<?=`・`>?=`の既定処理 | `lib/core.rusk`の型引数付き関数 |
| 整数の`sum` | `lib/core.rusk`の`extern`関数。高速な検査付き集計をC++で実装 |
| 配列の格納・添字・イテレータ、辞書・集合など | 型に応じた処理系の支援とC++の実装 |

`find`にはコンパイラ専用の展開はなく、普通の関数と同じ型引数の推論・具体化を使います。`a.find(x)`と`find(a, x)`の両方で呼べ、`find::<Int>(a, x)`も使えます。比較結果にはBoolが必要です。比較後にもイテレータの有効性を確認するため、比較が配列を構造変更した場合は、一致が見つかった場合も実行時エラーになります。

## 配列の操作

| API | 振る舞いと計算量 |
|---|---|
| `len(a: Vec<Int>)` | 要素数を独立した `Int` で返す。定数時間 |
| `push_back(a: Vec<Int>, x: Int)` | `x` を共有して末尾に追加。償却定数時間 |
| `copy(a: Vec<Int>)` | 各要素をコピーした新しい配列。時間・追加メモリとも要素数に比例 |
| `__assign__(a: Vec<Int>, b: Vec<Int>)` | 外側の `a` を保ち、各要素を新しくコピーして置換。時間・追加メモリとも `b` の要素数に比例 |
| `__getitem__(a: Vec<Int>, i: Int)` | 範囲を検査して要素を共有。定数時間 |
| `__setitem__(a: Vec<Int>, i: Int, x: Int)` | 範囲を検査して格納先を `x` に結び直し、`x` を共有して返す。定数時間 |

配列の拡張後も、取得済みの要素への共有は有効です。空配列は条件で偽、それ以外は真になります。添字とコピーの例は [言語リファレンス](../reference/index.md) を参照してください。

`[x; n]` はコピーに対応する初期値を要素ごとにコピーして配列を作ります。構造体・タプルにも対応します。時間・追加メモリとも要素数に比例します。`a.len()` や `a.push_back(x)` のようなメソッド形式も使えます。

配列操作は `Vec<Int>` 以外の対応要素型にも使えます。`in a(n): Vec<T>;` は `n` 個の値を読みます。β05ではタプルと多次元配列の一括入力にも対応します。[辞書・集合と入力API](beta05.md)を参照してください。`Bool` の入力は `Yes` / `No`、`true` / `false`、`1` / `0` を受け付けます。

| API | 振る舞いと計算量 |
|---|---|
| `sort(a)` | 要素の値で安定ソート。O(N log N)。要素の共有を保つ |
| `sorted(a)` | 外側だけ新しい配列を作り安定ソート。要素は元の配列と共有 |
| `reverse(a)` | 配列を反転。O(N) |
| `bisect_left(a, x)` / `bisect_right(a, x)` | 昇順配列の挿入位置を `Int` で返す。O(log N)。整列済みであることは呼び出し側の責任 |
| `contains(a, x)` | 値が等しい要素の有無。O(N) |
| `a + b` / `a += b` | 要素を共有して連結。`+=` は外側の同一性を保つ |
| `sum(a: Vec<Int>)` / `sum(a, initial)` | 検査付き加算を先頭から行う。初期値は省略時0。独立した `Int` を返す。O(N) |
| `min(a: Int, b: Int)` / `max(a: Int, b: Int)` | 独立した最小値・最大値。定数時間 |
| `abs(x: Int)` | 独立した絶対値。最小の64ビット整数はオーバーフロー |

多次元配列の比較・ソート・探索では値を再帰的に比較するため、要素の比較コストが加わります。β04の `pop_back` は末尾を削除して要素を共有で返します。空ならエラーです。スライスは未実装です。

## 文字列操作と型変換

| API | 振る舞い |
|---|---|
| `len(s: Str)` | ASCII 文字数。定数時間 |
| `s[i]` | 文字を共有。負数の添字も可能。定数時間 |
| `a + b` / `a += b` | 文字列の連結。`+` は独立した文字列 |
| `push_back(s: Str, c: Char)` | 末尾に1文字追加 |
| `contains(s: Str, x: Str)` / `contains(s, c: Char)` | 部分文字列・文字の有無 |
| `Int(x)` | `Int` のコピー、`Bool` の0/1、`Char` の ASCII コード、`Str` の整数解析 |
| `Bool(x)` | 基本型・配列の真偽変換 |
| `Char(x)` | `Char` のコピー、`Int` / `Bool` の ASCII コード変換、長さ1の `Str` の変換 |
| `Str(x)` | 基本型の文字列表現、`Vec<Char>` の連結。`Bool` は `Yes` / `No` |
| `Int()` / `Bool()` / `Char()` / `Str()` | それぞれ0、偽、NUL文字、空文字列 |
| `Char + Int` / `Char - Int` / `Char - Char` | ASCII 内での文字の移動、コード差。範囲外は実行時エラー |

整数変換は文字列全体を検査し、不正な形式と範囲外を実行時エラーにします。文字への共有がある場合の文字列の変更制限は [言語リファレンス](../reference/index.md) を参照してください。

構造体とタプルの配列で使える操作の範囲、自作の汎用ライブラリは [β02の型とライブラリ分割](../reference/beta02.md) を参照してください。
