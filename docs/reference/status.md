# 対応機能と制限

この表はRusk β08開発版の実装範囲です。開始時点ではfixしたβ07の機能を引き継いでいます。効果・戻り値の共有・脱出の解析、fixed/rebindable・readonly/mutable・noescape/escapeの契約検査に対応しています。解析結果を使う引数借用、閉じたInt・Bool・Charの値保持、配列要素とその別名の借用も実装しています。[β07の実装と検証](../development/beta07.md)と各注釈のページに、保守的に拒否する場合や最適化の制限を記載しています。リポジトリの`design/`にある将来の設計が、そのまま使えるという意味ではありません。

β08で進めるライブラリ定義の汎用化とジェネリックextern等は、[開発方針](../development/beta08.md)の対象です。外部ジェネリック型・関数とC++型参照には[最小試作](../development/beta08-extern-prototype.md)がありますが、記法は暫定で、コールバック・効果情報との接続やライブラリ移行は未完了です。以下の表は現在使える機能を示します。

## 実装済み

| 分類 | 対応内容 |
|---|---|
| 基本値 | 符号付き64ビット`Int`、`Bool`、ASCIIの`Char`・`Str`、`Unit` |
| 変数 | 型推論・型注釈、共有・コピー、更新と結び直し、スコープ、[readonly/mutable](access.md)、初期化前の使用検査、[fixed/rebindable](bindings.md) |
| 演算 | 検査付き整数演算、比較の連鎖、短絡論理、`&`・`\|`・`^`、最小・最大と更新 |
| 制御 | if文・式、ブロック式、for・while・loop、ループelse、ラベル付きbreak・continue |
| 型 | 配列、タプル、構造体、型引数、payload付きenum、Option |
| パターン | 入れ子、リテラル、構造体、or、ガード、match文・式、if let・while let |
| 関数 | [noescape/escape](escape.md)、再帰・相互再帰、オーバーロード、型引数、関数値、捕捉する無名関数 |
| ライブラリ | 辞書・集合、遅延走査、集計・探索・ソート、各種データ構造 |
| ツール | C++生成、IR出力、位置付き診断、ローカルとCIの検証 |

## 現在使えないもの

- 浮動小数点型、Unicodeの文字列操作、任意精度整数。
- シフト、ビット反転、ビット複合代入、`++`・`--`、`else if`、`do while`。
- スライス、配列・範囲・`@`パターン、if letチェーン。
- 値付きbreak、ブロックに付けるジャンプ用ラベル。
- 内側の名前付き関数、名前付き・既定引数、無名関数の引数型省略。
- 型消去した共通の関数型、トレイト、mixin。
- 自身を再帰的に含む型定義、例外処理、LLVMバックエンド。

## 書くときに気を付ける境界

`let a := [];`は要素型を決められません。`let a: Vec<Int> := [];`のように型の手がかりを与えます。配列に格納できる型や、比較・ソート・入出力ができる型にはそれぞれ条件があり、すべての型で全操作が使えるわけではありません。

タプルは2要素以上です。Unitの値は`{}`などで作り、値の式として`()`は使いません。一方、パターンの`()`はUnitに一致します。

文字列の文字を共有している間は、元の文字列の長さを変更できません。配列走査中の構造変更も検査します。詳細は[配列と文字列](../library/sequences.md)を参照してください。

コンパイル時にすべての実行時エラーを予防するわけではありません。添字、ゼロ除算、オーバーフロー、不正入力、Optionの不正な取り出しなどは[位置付きの実行時エラー](errors.md)になります。
