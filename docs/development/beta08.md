# β08の開始点と実装方針

fixしたβ07の最終コミット[`ed925d2`](https://github.com/shogo314/rusk_b_07/commit/ed925d2b107125e3a95957ddaa1689657e95bfa5)を引き継ぐ。[全テストCI](https://github.com/shogo314/rusk_b_07/actions/runs/42616455056)と[文書公開](https://github.com/shogo314/rusk_b_07/actions/runs/42616455127)の成功を確認し、このリポジトリでGit履歴を新しく開始した。

## β08の目標

externを含む通常のライブラリ定義で機能を表現し、コンパイラ内の関数名・型名ごとの専用実装と文字列置換を減らす。C++のextern本体も使い、名前解決・型検査・具体化・コールバック呼び出しを共通の仕組みに寄せる。[要件](https://github.com/shogo314/rusk_b_08/blob/main/design/beta08.md)に進め方と完成条件をまとめる。

まずmap/filter/fold等、コンテナ操作、Vecの宣言の具体化、標準関数の直接展開を棚卸しする。その後、不足するジェネリックextern・外部型・静的コールバックの仕組みを設計し、移行対象を選ぶ。新しいライブラリ機能の追加に、その名前のコンパイラ分岐が必要ない状態を目指す。

## 開始時点の実装

言語機能・標準API・処理系はβ07と同じで、β08向けのジェネリックextern等はまだ追加していない。効果・共有・脱出の解析、readonly/mutable・fixed/rebindable・noescape/escapeの契約、スカラーの値保持と借用、宣言・別名・呼び出し先内部の診断を引き継ぐ。

通常401件・最適化無効241件、サニタイザー35例、公開ジャッジ51解答の検証基盤を維持する。文書から抽出した20例と違反例・診断例も通常版と最適化無効版で検証する。開始点の数値は上記のβ07のCIによるもので、β08の新機能の検証結果ではない。

## 性能の比較元

[β07の成果と残る制限](beta07.md#beta07-review)と[性能記録](beta07-performance.md)を比較元にする。Option・遅延走査・find・Fenwick・sumを含む既存の対照を維持し、時間と確保数・共有コピー数を分けて調べる。共有・コピー・寿命・エラー位置を保ち、測定は他の検証と重ねない。

sumは開始時点ではC++実装を使う。ヒープ解析や借用の精密化は、ライブラリ定義の汎用化と測定結果を見て対象を選ぶ。
